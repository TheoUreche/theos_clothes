# Theo's Clothes — Storefront

One page storefront for [@theos_clothes](https://www.grailed.com/theos_clothes) on Grailed and [Depop](https://www.depop.com/theos_clothes/).

## Features
- Live inventory sync from Grailed (every 60 s) (w/ `data.js` as an offline fallback)
- Search, category, designer, size and sort filters
- Quick view w/ direct link to each Grailed listing
- Offer form and newsletter sign-up, delivered by email via FormSubmit
- Saved/liked items (stored in the browser)
